## Challenges
-Was applyng flexbox properties where they do not work when there is no available space whether in the main or cross axis
-Was applyting a flexbox property "gap" on normal flow and gap only works when a container is a flex container

## Solutions
-Used gap when properties like justify content and align items did not work, as this will work anyway even with the less space we have and it worked well 
-Applying margin and padding works on normal flow elements like block and inline clock but I preferred using flexbox items so I searched why it didnt work so I changed the dispay to access the flexbox properties I prefer like "Gap"

## What I learned
-I learned that the property gap works only when an element is a grid or a flex container
-Gap property works even when there is less space
-Flexbox properties (align items & justify content) will work only when theres available space in the main axis or in the cross axis
