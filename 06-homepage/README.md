# 06 - Homepage

## Concepts practiced
- Layout composition

## Challenges
- Getting the sidebar height and footer right, since the footer didn't sit at the bottom of the page
- Centering and aligning elements in the hero section
- Working out whether the design was meant to fit one screen or scroll

## Solutions
- Researched the problems properly and asked people in my group for help

## What I learned
- Plan class names before starting the implementation
- Keep the number of class names low for cleaner HTML, and spot which parts repeat so they can share styles
- Check early whether a design fits one screen or scrolls, because that changes how the layout is built

## Next improvements
- Get the spacing, positioning and alignment of elements closer to the design
